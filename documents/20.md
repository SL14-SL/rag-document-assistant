## S1: Format

CSV files must be UTF-8 encoded and use commas as delimiters. Required columns are external_id, title and status. Valid status values are open, pending and closed. The maximum file size is 10 MB.

## S2: Error handling

Duplicate external_id values within a file cause rejection of the entire file. For other invalid rows, valid rows are imported and errors are logged per row. Reimporting an existing external_id updates the existing ticket.
