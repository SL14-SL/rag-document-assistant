# Answer acceptance criteria

An answer passes only if all applicable criteria below are satisfied.

## Correctness
- No statement contradicts the supplied evidence.
- No unsupported factual assumptions determine the conclusion.
- Additional explanations must be supported, not just the main answer.

## Completeness
- All required claims for the question are covered.
- Conditions that materially affect the conclusion are preserved.
- Annual limits must not be presented as per-request allowances.
- Required approval must not be presented as guaranteed approval.

## Source support
- Source IDs exist among the supplied passages.
- Each cited passage supports the associated statement.
- A valid source ID alone does not establish support.

## Conflicts and missing information
- Conflicting rules are reported without arbitrarily selecting one.
- Missing information is acknowledged.
- If a conclusion depends on an unknown detail, give a conditional
  answer or ask for that detail rather than inventing it.
- Silence in the documents does not establish a prohibition.

## Presentation
- Source IDs should use square brackets.
- Repetition and unnecessary introductions are recorded separately
  from factual failures.

## Evaluation procedure
- Use the same criteria for all models.
- Record failed and successful cases.
- Keep original questions and runs unchanged.
- Diagnostic reformulations do not replace failed original questions.
- Keep validation questions unused during development.
- These criteria do not imply a production reliability guarantee.
